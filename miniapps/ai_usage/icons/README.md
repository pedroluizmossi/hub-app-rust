# Ícones das assinaturas

Ilustrações vetoriais para identificar os serviços no MiniUtils, inspiradas nas
identidades de Claude Code, Codex, Kiro e OpenCode. As marcas e seus nomes
pertencem aos respectivos titulares; os ícones não indicam associação ou endosso.

Referências: [Claude Code](https://code.claude.com/),
[Codex](https://openai.com/codex/), [Kiro](https://kiro.dev/about/) e
[OpenCode](https://opencode.ai/brand).
